# HARV2020 bird survey structure audit

A bounded methods note by Alexander Richard Towell, with substantial AI assistance.
It audits recording structure in a pinned NEON-derived bird subset and gives explicit synthetic witnesses to information lost by source-to-derived projections.

Exact version: [10.5281/zenodo.23496031](https://doi.org/10.5281/zenodo.23496031).

Read the [technical note](NOTE.md), [citation](CITATION.cff), [fresh AI review](REVIEW.md), [structured record](record.json) and [public-download receipt](publication.json). The [computational archive](../../artifacts/survey-structure-audit-v1.0.0.tar.gz) reproduces offline with Python 3.12 standard library and base R. It is byte-identical to the reviewed prepublication candidate; the separate release citation/status supersede historical draft metadata inside it.

The derivative contains 536 of 540 possible standard unit-minute strata across 90 provisional point units, with 34 incidental rows. Synthetic histories establish a conditional information-loss result. Original raw joins, survey completion and predictive accuracy remain unvalidated. No observed source bug, biological discovery, novelty or human peer review is claimed.

NEON and the Li et al. neonDivData resource are credited in the note. Code is MIT, original prose CC BY 4.0, and predecessor inputs retain CC0. The first public disclosure of this audit is 20 October 2026 on Zenodo; the predecessor's April 2026 date is recorded separately. Development remains in the owning discovery project. The exact archive/hash is the canonical source; no source Git commit is invented.
