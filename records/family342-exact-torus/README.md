# Exact all-parameter algebra for the four-torus cone example

[Version 1.0.0 DOI](https://doi.org/10.5281/zenodo.23532784) · [Canonical source](https://github.com/queelius/openai-math-counterexamples/tree/1a58edaaccb3084f1a2252ed2dfc2e1fa19efc3b/rows/342/exact) · [PR14](https://github.com/piiiico/openai-math-counterexamples/pull/14)

Alexander Richard Towell, with substantial OpenAI Codex assistance.

The contribution independently verifies twenty polynomial/exterior-algebra
identities in OpenAI's four-torus example, supplementing Pico/Håkon Åmdal's
sampled replay. The written argument gives a 1/sqrt(2) positivity bound for
the original amplitudes and the direct parameter consequence 0<|a|<1,b!=0.
It corroborates the source construction; it does not claim a new counterexample.

Fifteen tests pass in normal and optimized Python; three deliberate mutations
reject. One scoped AI reviewer found no blocker. All twenty source packet
files match their public Git blobs; all 23 archival manifest entries and the
public ZIP download were hash verified. Run `bash packet/reproduce.sh` after
extracting the archive, using the Python standard library.

Pointwise identities are exact computations. Positivity inequalities, the
periodic primitive, flat-torus Hodge facts and cohomological deductions are
written mathematics. There is no kernel proof, human peer review, general
cone-theorem verification, or exhaustive novelty assessment. PR14 remained
unaccepted at archival preparation.
