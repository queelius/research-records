Alexander Richard Towell, with substantial OpenAI Codex assistance.

calculation to three equilateral triangles. For a transcendental real parameter
`0<t<1/4`, the nine distinct unit-circle points have an exact tensor-criterion
obstruction. The algebraic result has a written proof and exact symbolic checks;
**the non-Ramsey consequence remains conditional on OpenAI’s classification**.
