# Fractional-knapsack construction and rounding bounds

Three complete accepted Lean proofs establish an actual fractional-knapsack
optimizer, the factor-two rounding inequality, and the refined small-item bound
for nested-logit utilities. **Version 1.1.0 is archived at
[10.5281/zenodo.23526994](https://doi.org/10.5281/zenodo.23526994).**

Read [the technical note](NOTE.md), [exact scope and credit](record.json), and
[publication receipt](publication.json). The self-contained ZIP contains all
three accepted proofs, three required platform definitions, pinned Lean/Mathlib
setup, the established verifier, complete target/axiom audits, logs and rejecting
controls. No Prove2Me account is needed to reproduce the archived sources.
All three public downloads and all 68 files inside the archive were verified.

Original mathematics belongs to Guillermo Gallego and Huseyin Topaloglu; the
shared model also credits James M. Davis. mikedeng1's platform formulations,
Shuze Chen's statement review and Lean/Mathlib infrastructure retain specific
credit. Alexander Richard Towell directed; OpenAI Codex substantially developed,
verified and documented the formalization. No mathematical novelty or independent
human proof review is claimed; see [NOTICE.md](NOTICE.md).

Version 1.0 was a public metadata record for two rounding bounds. This first
archival edition adds the optimizer construction and reproducibility evidence.
The uniform quadratic candidate-family bound and full assortment-revenue theorem
remain open. The owning project retains the detailed lifecycle and stays private;
research-records supplies the curated public index.
