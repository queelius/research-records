# Verified knapsack rounding guarantees

Two complete Lean proofs formalize Gallego and Topaloglu's factor-two and
small-item utility guarantees for optimal LP points. Exact scope, assumptions,
platform links, proof hashes and source versions are in [record.json](record.json).
See the [technical note](NOTE.md) and [verification summary](verification.json).

Alexander Richard Towell (queelius) directed the work; OpenAI Codex substantially
formalized and checked it. The source authors, platform formulation by mikedeng1,
statement review by Shuze Chen and Lean/Mathlib contributors retain credit.
James M. Davis, Guillermo Gallego and Huseyin Topaloglu supplied the mathematics
behind the shared nested-logit instance interface.
This records formalization of established mathematics, with no novelty or
independent human review claim.

The Prove2Me project owns the proofs, evidence and research lifecycle; this
central entry curates the result across projects and pins the owning source
commit. No DOI or self-contained public proof packet is assigned. The full
greedy construction, finite candidate-family construction and assortment-revenue
theorem remain separate obligations.
