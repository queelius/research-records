# Verified mixed-regularity contraction for relaxed Peaceman–Rachford splitting

For actual relaxed PRS iterates and a supplied fixed point in an arbitrary real Hilbert space, the exact C43 distance bound holds when strong convexity and smoothness lie in opposite summands, in either orientation. Also establishes the general auxiliary estimate and mixed decrease and distance bounds.
