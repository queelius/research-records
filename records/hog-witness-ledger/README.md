# House of Graphs witness ledger

Alexander Richard Towell's ledger of **26 House of Graphs witness graphs**:
C6, C5, K4, P4 and P5 saturation and three Zarankiewicz z(m,n;3,4) graphs.
Each witness is stored byte-exact as graph6 and counts as checked only when a
pure-Python checker and a separate NetworkX implementation, sharing no code,
both verify its defining property.

The [exact version 1.0.0 archive](https://doi.org/10.5281/zenodo.23550688)
is the tagged [public repository](https://github.com/queelius/hog-contrib/tree/v1.0.0).
Installed from the extracted archive, the gate verified all 26 witnesses and
all 65 tests passed; the archive rebuilds byte-identically from the tag, and
the public download matches its SHA-256.

The ledger asserts verification, not novelty. Each record states its own
claim with dated prior art: 10 known values, 6 new values,
1 new classification, 1 correction and 8 unassessed. A witness
establishes attainment; exact values rest on the lower-bound evidence in each
record's cited archive, such as the
[C6 saturation record](../small-order-c6-saturation/README.md). House of
Graphs and the credited prior work retain their credit. Substantial Claude
Code and OpenAI Codex assistance is disclosed; there is no human peer review.

The owning project is `hog-contrib`. See [record.json](record.json) for the
structured scope, [publication.json](publication.json) for verified public
file hashes, and [CITATION.cff](CITATION.cff) for the exact version citation.
