# Prove2Me formalization collection

**Version 1.0.0, published 23 October 2026:** [10.5281/zenodo.23590811](https://doi.org/10.5281/zenodo.23590811).
The evolving collection is identified by [10.5281/zenodo.23590810](https://doi.org/10.5281/zenodo.23590810); cite the version DOI for these exact files.

This edition catalogs 291 accepted targets and contains full source and evidence packets for 288: 283 proofs and 5 disproofs. Three additional targets are metadata-only because two older dependency redistribution grants remain unconfirmed. The archive includes 222 platform source files and preserves the exact accepted sources and original evidence.

A fresh Lean 4.33.1/Mathlib replay passed all 288 target audits and 222 platform modules, with 522 successful command receipts. Proof-byte mutation and untrusted-axiom controls both rejected. The deterministic ZIP has 2,219 files; an identical rebuild, all public-download byte comparisons, every internal manifest hash and extracted archive integrity passed. Pinned compiled Lean/Mathlib caches were reused; a source-only dependency rebuild was not tested.

The archive preserves statements, dates, source pins, licenses, predecessor credit and human/AI roles independently of Prove2Me hosting. Alexander Richard Towell directs and stewards the work. Original mathematics, platform/community contributions and substantial Codex assistance are separately credited; Claude Code contributed repository organization and collection planning. No mathematical novelty or independent human peer review is claimed. Existing focused DOI families remain canonical and are linked from the collection.
