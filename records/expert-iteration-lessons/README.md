# Expert Iteration: Experiments and Lessons

Alexander Richard Towell, Southern Illinois University Edwardsville.
ORCID: https://orcid.org/0000-0001-6443-9897.

This is a pedagogical research archive of search-assisted policy learning and
frozen-language-model orchestration. It preserves bounded findings and a
small teaching example. It does not establish a new successful controller or
complete the proposed study of RL/search sample efficiency.

The archive reconstructs eight descriptive comparisons from saved individual
outcomes, without new inference or independent mathematical rescoring.
The tested imitation controller transferred poorly. A fixed revision supplied
more correct candidates than the tested coordinator selected on shared saved
problems; the comparison was not cost matched. Local context helped relative
to full context in a twelve-state screen, but the selected fixed child tied
direct prompting and state-specific selection failed the original criteria.

All 59 tests in the compact packet passed in a fresh environment with no
provider credentials, Torch, SymPy, models, or sibling projects. Both generated
table files matched exactly. All four release files were downloaded from
Zenodo and GitHub without authentication and their SHA-256s matched.
Separate historical symbolic-replay timeouts remain documented.

Original software is MIT; new notes are CC BY 4.0. The packet retains model
and benchmark notices. No worker model weights are included in it.
